🌟 ลอการิทึมคืออะไร?

ลอการิทึมเป็นการดำเนินการที่ย้อนกลับของการยกกำลัง ใช้ตอบคำถามว่า “ต้องยกกำลังฐานเท่าใด จึงจะได้ผลลัพธ์ที่กำหนด”

ax = N  ⇔  logaN = x
เงื่อนไขสำคัญ: a > 0, a ≠ 1 และ N > 0
ตัวอย่าง: 2³ = 8 ดังนั้น log₂8 = 3

🔎 ส่วนประกอบ

logaN = x

a = ฐาน N = จำนวนจริงบวก x = เลขชี้กำลัง

ค่าลอการิทึมคือเลขชี้กำลังที่ทำให้ฐานยกกำลังแล้วได้ N

🪄 ตัวอย่างชวนคิด

log₃81 = ?

เพราะ 34 = 81

log₃81 = 4

ลองตรวจสอบด้วยการเขียนกลับเป็นรูปเลขยกกำลัง

🧁 สมบัติพื้นฐานของลอการิทึม

ผลคูณlogₐ(MN) = logₐM + logₐN
ผลหารlogₐ(M/N) = logₐM − logₐN
เลขยกกำลังlogₐ(Mᵏ) = k logₐM

เมื่อ M,N > 0, a > 0 และ a ≠ 1

สังเกต: กราฟ y = aˣ และ y = logₐx เป็นภาพสะท้อนกันเมื่อเทียบกับเส้น y = x เพราะทั้งสองฟังก์ชันเป็นฟังก์ชันผกผันกัน

🧠 ภารกิจนักสำรวจ

  1. ปรับฐาน a จาก 1.2 ไปถึง 4 แล้วสังเกตความชันของกราฟ
  2. ปรับเลขชี้กำลัง x เป็นค่าติดลบ แล้วสังเกตค่า aˣ
  3. อธิบายว่าเหตุใด logₐ(aˣ) จึงได้ค่าเท่ากับ x
